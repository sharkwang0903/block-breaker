# Block Breaker｜打磚塊

依照 `GAME_SPEC.md` v1.0 製作的網頁打磚塊遊戲，使用原生 HTML、CSS、JavaScript 與 Canvas 2D。JavaScript 按功能分檔，沒有第三方套件、遊戲引擎或建置步驟。

## 開始遊玩

1. 用 Chrome 或 Edge 開啟專案根目錄的 `index.html`，直接雙擊即可。
2. 選「正常模式」或「無限模式」。
3. 按 `Space` 或畫面「發球」按鈕開始。

可以離線遊玩，不需要安裝 Node.js、Python 或啟動伺服器。請保留 `index.html`、`products.html`、`style.css`、`js/` 與 `assets/` 的相對位置；搬移遊戲時搬整個資料夾。官網商品連結需連上網路才能開啟。

## Pink 水母應援與水母電擊

遊戲右側加入獨立 Pink 應援區，下方顯示能量條與水母電擊按鈕；手機直向改成遊戲區上方的小橫條。提供陪伴、加油、小驚訝、大招施放四種透明 PNG，搭配 CSS 漂浮、彈跳及短暫搖動。打掉四塊磚會加油，進入下一關會慶祝，失去生命時會鼓勵；施放大招時切換專屬姿勢。系統設定減少動態效果時會停止角色動畫，雷電改用簡單直線，保留功能與表情切換。

素材位於 `assets/pink/`，`pink-wave.png` 為使用者提供的原始 Pink 圖，其餘四張使用內建 imagegen 依原圖生成。生成提示與來源記錄於同目錄的 `prompts.json` 及 `pink-cast.prompt.json`。動畫由 `js/companion.js` 與 `style.css` 控制。

成功由球拍回擊每顆球增加 1 點能量，接到正面商品增加 5 點（滿生命時接到 SIRT+10 也會增加）；負面道具、打磚、雷電、藏球生成及發球不加能量。上限 25，掉球與跨關保留；重新開一場歸零。滿格時顯示提示，進行中按 `Space` 或點「水母電擊」施放。待發球時 `Space` 優先發球，下一次按鍵才施放；按住按鍵不連發。

施放立刻消耗全部能量，雷電在 3 秒內分次挑選仍存在的可破壞磚塊，包含爆炸連鎖最多消滅 10 塊。直接命中的強化磚一次擊破，障礙不受影響，道具與藏球照常發放，仍正常計分。期間球照常運動並可重新蓄能，同一時間只能有一個大招；暫停與掉球後待發球會凍結大招計時，重新發球後繼續。跨關或結算會結束當次大招，避免攻擊新關卡。雷電線條與命中光圈由 Canvas 繪製。

| 裝置 | 移動球拍 | 發球 | 暫停 |
|---|---|---|---|
| 桌機 | 按住 `←`／`→` | `Space` 或發球按鈕 | `Esc` 或右上角暫停按鈕 |
| 手機 | 在遊戲區按住並左右拖曳 | 發球按鈕 | 右上角暫停按鈕 |

初始與失去生命後需主動發球；正常過關會直接繼續。暫停選單提供繼續、重新開始與回首頁，後兩者會先確認是否放棄進度。視窗離開焦點或切換分頁時會自動暫停。

大招控制：進行中滿能量按 `Space`，或點 Pink 下方的「水母電擊」。

## 商品道具與介紹頁

四款正面道具已實裝為商品：PPA／減速、BF01+1／球拍加長、QCC／穿透、SIRT+10／生命＋1。商品以 64 × 64 邏輯像素圖框顯示，保留原比例，接取範圍依可見包裝寬高設定。負面道具維持原本 22 px 警示圖示。

十關各配置六塊道具磚，從原有普通磚替換，保留原排列、磚塊總數與其他特殊磚。其中四塊各保證掉落一款商品，位置跨不同區域，商品對應隨關卡輪換；另外兩塊隨機抽取正面 80%、負面 20%。擊破全部道具磚後，每關會掉落 4～6 個正面商品，四款至少各一次。連鎖爆炸、穿透破壞與無限模式循環都套用相同規則，仍需球拍接到才生效。

接到商品會短暫顯示商品名稱與效果，Pink 也會歡呼。底部效果列保留商品名稱、效果符號及倒數；SIRT+10 在生命上限時提示「生命已滿」。暫停會停止掉落、效果與接取提示的倒數。圖片尚未載入或載入失敗時，暫以原本道具符號顯示。

通關與失敗結算皆提供「了解這些獎勵道具」，另開 `products.html`，保留原結算畫面。介紹頁只列四款商品、各自在遊戲中的效果／持續時間，以及使用者提供的四個官網商品連結；官網連結也另開分頁。透明 PNG 與生成提示存於 `assets/products/`。

## 手機與網站發布

支援手機直向、橫向及觸控操作。發布成 GitHub Pages 等靜態網站後，手機用瀏覽器開啟網站網址即可遊玩。單純上傳 GitHub 儲存庫是存放原始碼，需另外啟用網站發布，才會有遊戲網址。

網站入口是根目錄的 `index.html`；保留 `products.html`、`style.css`、`js/` 與 `assets/`，不需要安裝套件或執行建置指令。

目前僅保留兩個正式 HTML：`index.html` 是遊戲，`products.html` 是獎勵道具介紹。早期使用的 Pink 動畫展示頁、PPA 尺寸比較頁與測試截圖已移除。`output/` 已加入 `.gitignore`，之後產生的檢查截圖不會納入 Git 版本控制。

上傳 GitHub 時，建議一併保留 `README.md`（操作與維護說明）、`GAME_SPEC.md`（設計規格）及 `tests/`（商品與大招的自動檢查），方便後續維護；瀏覽器執行遊戲不會載入這些檔案。`assets/` 中的來源圖片與提示紀錄則供日後修改角色、商品素材時參考。

```text
block-breaker/
├─ index.html              首頁、HUD、發球、暫停與結算介面
├─ style.css               配色、字體、桌機／手機版面
├─ products.html           四款商品、遊戲效果與官網連結
├─ assets/pink/            透明 PNG、原始 Pink 圖與生成提示
├─ assets/products/        商品透明 PNG 與生成提示
├─ js/
│  ├─ control-selection.js 滑鼠與鍵盤共用單一按鈕選取狀態
│  ├─ config.js            集中遊戲數值與 Canvas 字體
│  ├─ levels.js            固定 10 關及無限模式模板循環
│  ├─ bricks.js            耐久、連鎖爆炸、藏球與磚塊計分
│  ├─ powerups.js          道具掉落、接取、共享效果與倒數
│  ├─ physics.js           球、牆壁、球拍與下降磚塊碰撞
│  ├─ ultimate.js          能量累積、施放、雷電目標與十塊上限
│  ├─ game.js              生命、多球、過關與遊戲狀態
│  ├─ renderer.js          Canvas 繪圖與輕量動畫
│  ├─ input.js             鍵盤、觸控與焦點處理
│  ├─ companion.js         Pink 表情與應援反應
│  ├─ ui.js                資訊列、暫停、確認與結果視窗
│  └─ main.js              啟動、主迴圈與功能協調
├─ README.md               使用說明、結構、參數與驗證摘要
├─ GAME_SPEC.md            原始遊戲設計規格
├─ tests/                  商品道具與水母電擊自動檢查
└─ .gitignore              忽略系統暫存檔與產生的檢查輸出
```

遊戲與道具介紹需要 `index.html`、`products.html`、`style.css`、`js/` 與 `assets/`。各 JS 檔用立即執行函式隔離作用域，透過 `globalThis.BlockBreaker` 共享公開介面，由 HTML 按依賴順序載入一般 script，支援 `file://` 與 HTTP。

球、磚塊、特殊符號、道具與碎片都由 Canvas 原生繪製；頁籤圖示是內嵌 SVG，Pink 應援角色使用本機 PNG 素材，沒有遠端資源請求。

## 遊戲規則

- 正常模式固定 10 關；無限模式重複相同 10 關模板，沒有隨機生成或額外難度曲線。
- 初始 3 條生命，上限 5 條。多球時個別球掉落只移除該球，最後一球掉落才扣生命。
- `O` 藏球磚塊每破壞一塊直接釋放一顆球，沒有球數上限。每塊可破壞磚塊恰好 +50 分。
- `B` 一般、`H` 強化、`X` 爆炸、`S` 障礙、`D` 道具；`O` 為藏球子類。爆炸影響周圍八格並可連鎖，障礙不計入清關條件。
- 每關四個指定正面商品保底，加兩個隨機道具（正面 80%、負面 20%）；同類重置計時，相反效果互斥，所有球共享速度與穿透效果。
- 無縫接關保留球、球拍、有效道具及下落道具。新磚塊下降 0.7 秒，下降中即可碰撞、破壞與計分。
- 球與移動磚塊以連續碰撞及相對運動判定；反彈保留有效球速，生成重疊會在分離後恢復碰撞。

完整細節見 `GAME_SPEC.md`。

## 調整參數

| 項目 | 檔案與參數 | 目前值 |
|---|---|---|
| 球大小與實際碰撞半徑 | `js/config.js` → `CONFIG.ball.radius` | 9，直徑 18 邏輯像素 |
| 球速 | 同上 → `CONFIG.ball.speed` | 310 px/s |
| 球拍寬度／鍵盤移動速度 | 同上 → `CONFIG.paddle.width`／`speed` | 100／520 px/s |
| 商品顯示尺寸／商品對應 | 同上 → `CONFIG.powerups.productSize`／`products` | 64 px；名稱、圖片、效果提示與接取範圍 |
| 大招能量／持續時間／消滅上限 | 同上 → `CONFIG.ultimate` | 回擊＋1、商品＋5、25 點滿格、3 秒、10 塊 |
| 磚塊下降時間 | 同上 → `CONFIG.bricks.descentDuration` | 0.7 秒 |
| Canvas 耐久／道具字體 | 同上 → `CONFIG.visuals.fonts.durability`／`powerup`／`compactPowerup` | 17／18／14 |
| Canvas 關卡提示 | 同上 → `CONFIG.visuals.fonts.levelNotice` | 20 |
| Canvas 待發球文字／說明 | 同上 → `CONFIG.visuals.fonts.waitingTitle`／`waitingHint` | 22／18 |
| 介面字體整體縮放 | `style.css` 最上方 `:root` → `--font-scale` | 1；1.1 代表再放大 10% |
| 介面各類字體 | 同上 → `--font-small`、`--font-body`、`--font-button`、`--font-hud`、`--font-dialog-title` | 14／17／18／30／32 px |

球的繪圖與碰撞使用同一個半徑。配色、道具時間、落速及其他遊戲數值也集中於 `js/config.js`。修改後重新整理或重新開啟 HTML，再開始新遊戲即可。
